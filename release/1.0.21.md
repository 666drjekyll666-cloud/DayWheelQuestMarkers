# Day Wheel Quest Markers 1.0.21

Initial public release for **Graveyard Keeper 1.407**.

Day Wheel Quest Markers adds small markers to the weekday wheel when the player's current actionable objective requires interaction with a weekday-specific NPC.

Highlights:

- supports all six vanilla weekday NPCs;
- checks current quest actionability rather than marking every unfinished NPC quest;
- supports verified cross-owner objectives and two verified bridge quest chains;
- preserves the game's quest-marker categories and colors;
- supports multiple simultaneous actionable objectives on the same weekday;
- tracks weekday-wheel rotation and normal HUD/menu transitions;
- keeps normal gameplay overhead low through cached quest structure.

## Installation

Copy `Day Wheel Quest Markers 1.0.21.dll` into `Graveyard Keeper/BepInEx/plugins/` and restart the game.
