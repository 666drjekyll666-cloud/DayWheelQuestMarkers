# Day Wheel Quest Markers 1.0.23

Stable release for **Graveyard Keeper 1.407**.

This update broadens reminders beyond visible quest-completion steps: the weekday wheel can now also remind you about currently available authored one-time conversations with weekday NPCs.

Highlights:

- detects actionable one-time weekday-NPC dialogue through the game's own persistent dialogue state;
- keeps repeatable utility/menu choices such as Trade, Leave, Back, and non-consuming submenu headers out of the reminder set;
- preserves existing quest-linked, cross-owner, bridge, and verified intermediate reminder handling;
- respects supported item/resource/relation/quality gates and fails closed on unsupported structures;
- keeps graph discovery in the loading-screen prewarm so normal gameplay remains lightweight.

## Installation

Copy `Day Wheel Quest Markers 1.0.23.dll` into `Graveyard Keeper/BepInEx/plugins/` and restart the game.
