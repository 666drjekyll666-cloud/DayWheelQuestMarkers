# Day Wheel Quest Markers 1.0.24

Stable release for **Graveyard Keeper 1.407**.

This update keeps the accepted reminder behavior from 1.0.23 while simplifying and speeding up how the mod discovers weekday-NPC interactions during loading.

Highlights:

- uses one unified cache for quest-linked, cross-owner, and authored one-time dialogue reminders;
- parses each weekday-NPC dialogue graph once instead of through multiple independent caches;
- removes transitional hard-coded bridge/intermediate reminder tables and handles those verified one-time interactions through the same authored dialogue-state rule;
- preserves supported item/resource/relation/quality gates and native quest-marker styles;
- keeps normal gameplay lightweight with cached rules and no recurring dialogue-graph parsing;
- reduced measured developed-save prewarm from 782.89 ms in 1.0.23 to 308.07 ms in the accepted regression test.

## Installation

Copy `Day Wheel Quest Markers 1.0.24.dll` into `Graveyard Keeper/BepInEx/plugins/` and restart the game.
