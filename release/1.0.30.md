# Day Wheel Quest Markers 1.0.30

This release fixes false weekday reminders caused by nested dialogue options being treated as actionable when their parent menu path is still blocked.

- Adds general root-to-answer reachability for task-linked and one-shot dialogue reminders.
- Removes the temporary Charmel-specific exception in favor of the shared navigation model.
- Persists compact navigation predicates in the BepInEx cache so normal gameplay does not traverse FlowCanvas dialogue graphs.
- Preserves the low-overhead steady-state path and cheap known-NPC rebinding introduced by the recent performance work.
- Verified on Graveyard Keeper 1.407: the reported blocked Charmel state no longer shows the two false Lust-day markers, and a subsequent launch loads the persistent manifest in about 10 ms with graph parsing skipped.

Requires Graveyard Keeper 1.407 and BepInEx 5.x.
