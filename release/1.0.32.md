# Day Wheel Quest Markers 1.0.32

This release adds reminder coverage for several verified quest stages whose completion path is not represented by a normal selectable dialogue answer.

- Fixes the Inquisitor stage that begins with a mandatory interaction/cutscene: the weekday marker now appears when that interaction is actually ready.
- Adds verified coverage for later Snake stages that use event-driven or indirect completion paths while preserving their item, relationship, and navigation requirements.
- Reuses the existing persistent rule manifest and cached navigation data; normal gameplay still performs no FlowCanvas graph traversal.
- Keeps currently actionable authored one-time conversations as valid reminders even when the game does not show a journal task for them.
- Verified on Graveyard Keeper 1.407: the Inquisitor marker appeared before the mandatory scene, disappeared after completion, and a later marker returned only after the next resource prerequisite became satisfied.

Requires Graveyard Keeper 1.407 and BepInEx 5.x.
