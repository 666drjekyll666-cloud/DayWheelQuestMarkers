# Day Wheel Quest Markers 1.1.3

This release fixes duplicate weekday reminders around chained dialogue interactions and consolidates the reminder cache architecture.

### Changes

- Follow-up one-time choices that are reachable only after completing an already-reminded interaction no longer create extra markers for the same NPC visit.
- The Astrologer diary sequence now shows one reminder instead of three before the hand-in.
- Non-`@` one-time interactions now use the same persistent interaction manifest as the rest of the reminder system.
- The persistent cache is upgraded to schema 4 and rebuilds automatically when needed.
- Normal gameplay still performs no FlowCanvas graph parsing; verified cached reload completed in 10.42 ms.

Tested with Graveyard Keeper 1.407.
