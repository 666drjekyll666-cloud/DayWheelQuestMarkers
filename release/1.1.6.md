# Day Wheel Quest Markers 1.1.6

This release generalizes one-time dialogue reminders so the mod can recognize a complete authored interaction even when a child dialogue choice consumes its parent entry.

### Changes

- Replaces the Snake counterfeit-coins special case with the common nearest-lifecycle-owner rule.
- Supports the four independently verified child-consumed-parent interactions found across the six weekday NPC graphs.
- Keeps task-owned and same-visit interactions deduplicated so one visit does not create extra markers.
- Preserves authored item/relation/navigation requirements and fail-closed behavior.
- Upgrades the persistent cache to schema 5; normal gameplay still performs no FlowCanvas graph parsing.
- Verified Snake regression: **2 -> 1 -> 0** markers across counterfeit coins and Restoration Tools.

Tested with Graveyard Keeper 1.407.
